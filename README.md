# 🎯 GuessNumber

A simple and interactive **Number Guessing Game** built using **HTML, CSS, and Python with PyScript**.

## 🎮 About the Project

The game generates a random number between **1 and 100**. The player has to guess the number using the hints provided by the game.

After every guess, the game tells the player whether the entered number is **Higher** or **Lower** than the secret number.

Once the correct number is found, the game displays the number of attempts taken and provides a **Replay Game** option to start a new game.

## ✨ Features

- 🎲 Random number generation between 1 and 100
- ⬆️ Higher number hint
- ⬇️ Lower number hint
- 🔢 Attempt counter
- 🎉 Winning message
- 🔄 Replay Game option
- 🎨 Colorful user interface
- 🌐 Python running directly in the browser using PyScript

## 🛠️ Technologies Used

## 🚀 How to Play

1. Enter a number between **1 and 100**.
2. Click **Submit Guess 🚀**.
3. Follow the **Higher ⬆️** or **Lower ⬇️** hint.
4. Continue guessing until you find the secret number.
5. After winning, click **Replay Game 🔄** to start a new game.
